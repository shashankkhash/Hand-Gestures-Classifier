Spotting a downward hand in 960 pixels

A small neural network, written by hand without an ML framework, looks at a tiny grayscale photo of a hand and decides one thing: is this the “down” gesture or not?

The data

Four gestures, thirteen people, one question

Each photo is 32 pixels tall and 30 wide, in grayscale. Thirteen volunteers (A to M) each held their hand in four poses. The network only has to separate down from the other three, which makes this a yes-or-no problem.

How it works

Three layers and a lot of small corrections

Every pixel becomes a number between 0 (black) and 1 (white). Those 960 numbers feed 100 hidden units, and each hidden unit learns its own weighted mix of the pixels. A single output unit combines the hidden units into a score between 0 and 1. A score of 0.5 or more means “down”.

  1. Guess

    Pass a photo through the network and read the score, starting from small random weights.

  2. Measure the miss

    Compare the score with the right answer (1 for down, 0 otherwise) using squared error.

  3. Nudge every weight

    Backpropagation works out how much each of the ~96,000 weights caused the miss and moves it slightly the other way, with a learning rate of 0.1.

  4. Repeat

    Do this for every training photo, then go through the whole set again. The script runs 1,000 passes (epochs).

Training

It memorises the training set, and still generalises

For the first few dozen passes the network just says “not down” for everything. Then it starts picking up the shape of the gesture. Training accuracy reaches 100%, while accuracy on photos it never trained on settles around 91%, well above the 78% you would get by always saying “not down”.

About these numbers

The original script loops over every weight in plain Python. To make 1,000 epochs practical, the results here come from a NumPy version of the same algorithm: the same 960‑100‑1 sigmoid network, weight initialisation, per-photo updates, learning rate and epoch count, with a fixed random seed. The image lists in the repo name files that are not in the gestures/ folder, so training used the photos that exist. A different seed will move test accuracy by a few points.
